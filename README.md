# Paradise Nursery 

Paradise Nursery is a React-based houseplant shopping application. The application allows users to browse different categories of houseplants, add plants to a shopping cart, manage quantities, and view the total cost before checkout.

## Features
🌱 Landing page with company information and background image
🪴 Houseplants organized into multiple categories
🛒 Add plants to the shopping cart
🔢 Dynamic cart item count
➕ Increase plant quantities
➖ Decrease plant quantities
🗑️ Remove plants from the cart
💰 Calculate individual and total cart costs
🧭 Navigation between Home, Plants, and Cart pages
💳 Checkout button with "Coming Soon" message
